# OctoAcme Project Management Documentation

## Overview

OctoAcme manages projects through a five-phase lifecycle: **Initiation → Planning → Execution → Release → Close & Retrospective**. Teams validate the need and align stakeholders, plan small shippable increments, build and verify them, release with safeguards, then capture lessons for the next iteration. This approach prioritizes customer value, iterative delivery, clear ownership, and decisions informed by outcomes.

Regular PM/Product and delivery-team syncs, stakeholder updates, and timely risk escalation keep work visible. Acceptance criteria, code review, automated tests and security scans, QA, and pre- and post-deployment checks help protect quality throughout delivery.

## Key principles

- **Customer-first delivery:** Prioritize customer value and usability.
- **Iterative development:** Deliver small, testable increments and learn from feedback.
- **Clear ownership:** Name a Project Manager and Product Lead, and assign owners to work and risks.
- **Data-informed decisions:** Define success metrics and use evidence to guide priorities and improvements.
- **Psychological safety:** Encourage candid feedback and learning.

## Core roles

- **Project Manager (PM):** Coordinates schedules, risks, delivery, and stakeholder communications.
- **Product Manager (PdM) / Product Lead:** Defines outcomes, prioritizes the backlog, and measures success.
- **Developers:** Design, implement, test, and review changes.
- **QA/Testing:** Validates acceptance criteria and quality gates.
- **Stakeholders:** Provide input, alignment, and approvals.
